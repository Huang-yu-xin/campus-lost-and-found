```text

MAVEN_HOME=D:\maven\apache-maven-3.9.4-bin\apache-maven-3.9.4
MYSQL_HOME=D:\MySQL\mysql-8.0.34-winx64
```

IDEA Project SDK、Maven 导入 JDK、Maven Runner JRE 均应设置为 JDK 21。pom.xml 中设置 `<java.version>21</java.version>`。

当前全局 JAVA_HOME 和 PATH 仍指向 JDK 17，暂不修改。使用命令行构建本项目时，需要让该终端的 JAVA_HOME 与 PATH 指向 JDK 21；Maven Wrapper 固定 Maven 版本，不负责自动切换 JDK。
