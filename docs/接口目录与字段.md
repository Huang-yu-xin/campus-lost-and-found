# 校园失物招领系统接口目录与字段

版本：0.1.0-draft。接口定义以同目录 openapi.yaml 为准；业务前置条件见《接口文档》。全部路径前缀为 `/api/v1`。下列分工是沿用既有六组功能并补充的建议，不代表三人已实际完成工作。

错误响应的 HTTP 状态码与对应业务错误码见《接口文档》。写请求均需 CSRF 令牌，登录要求另列；匿名公开读取没有用户会话要求。

## 认证

### getCsrf 获取 CSRF 令牌

`GET /api/v1/auth/csrf`

负责人建议：甲；需求：SUP-01；范围：第一版合同范围。

匿名也可调用；必要时建立匿名会话，不产生已登录身份。登录、退出或改密后重新获取令牌。

登录：可匿名；描述中的条件权限仍需校验。成功：HTTP 200，CsrfDataResponse。

错误 HTTP：500。

### sendRegistrationCode 发送注册验证码

`POST /api/v1/auth/email-codes`

负责人建议：甲；需求：FR-01；范围：第一版合同范围。

6 位数字，5 分钟有效，绑定注册用途与邮箱；重发替换旧码，成功注册时原子消费。草案每邮箱与来源组合限制发送频率。演示邮件接收方式见 P-01。

登录：可匿名；描述中的条件权限仍需校验。成功：HTTP 200，CodeSentDataResponse。

请求体：`SendCodeRequest`。

错误 HTTP：400, 403, 415, 429, 500。

### register 注册并绑定校园身份

`POST /api/v1/auth/register`

负责人建议：甲；需求：FR-01；范围：第一版合同范围。

仅创建学生账号，不自动登录。模拟名册匹配、邮箱验证码和唯一性检查通过后原子创建。拒绝未知 role 字段。手机号可在个人资料补充。

登录：可匿名；描述中的条件权限仍需校验。成功：HTTP 201，MeResponse。

请求体：`RegisterRequest`。

错误 HTTP：400, 403, 409, 415, 500。

### login 登录

`POST /api/v1/auth/login`

负责人建议：甲；需求：FR-02；范围：第一版合同范围。

成功轮换会话 ID，返回当前用户；邮箱不作为登录账号。学号与卡号跨列冲突必须在建号时排除。登录失败不永久锁号，可临时限流。

登录：可匿名；描述中的条件权限仍需校验。成功：HTTP 200，MeResponse。

请求体：`LoginRequest`。

错误 HTTP：400, 401, 403, 415, 429, 500。

### logout 退出登录

负责人建议：甲；需求：FR-02；范围：第一版合同范围。

{
  "type": "string",

  "pattern": "^[1-9][0-9]*$",
