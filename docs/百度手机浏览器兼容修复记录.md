# 百度手机浏览器兼容修复记录

日期：2026-11-11。用户反馈百度手机版直接输入网址后，导航挤成窄竖列、品牌与账号区位于中间，且未启用电脑版网页。

## 定位与修复

源文件使用 `@media (max-width: 640px)`，但原生产构建将其压缩为 `@media (width<=640px)`，768px 等断点也发生相同变化。较旧的浏览器内核可能不识别这种媒体查询范围语法，从而忽略整个手机规则块。

在现代浏览器中模拟“忽略新媒体查询范围语法”，已复现菜单按钮消失、导航变成窄竖列和品牌／账号区垂直居中的布局失效模式。用户浏览器的具体内核版本尚未取得，因此该复现证明了现有构建兼容缺陷与相同失效机制，不作为真实百度内核实测的替代。

修复提交：`fbb4095637eca66acfbf471e19ac6a0266afa025`。

- 设置 Vite `build.cssTarget: 'chrome87'`，使生产压缩保留传统 `min-width`／`max-width` 媒体查询。
- 每次生产构建后检查全部 CSS 产物，发现比较运算符形式的媒体查询即构建失败，并确认 400、640、768px 断点保留。
- 新增旧媒体查询解析行为模拟的浏览器回归，检查菜单、个人卡片及资料表单。

这里的 `chrome87` 是 CSS 输出兼容目标，不表示整个网站已完成该版本全部 JavaScript、Web API 或真实浏览器验证。

生产构建与 CSS 检查、lint、应用及浏览器测试类型检查通过。Chrome、Edge 各 25 个浏览器场景通过，包括新增的旧解析行为回归；这是 25 个不同场景、50 次浏览器执行。没有将浏览器模拟改写为真实百度手机版测试通过。
