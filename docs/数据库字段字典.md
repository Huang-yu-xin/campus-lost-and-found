# 校园失物招领系统数据库字段字典

版本：0.1.0-draft。由 MySQL 8.0.34 隔离实例执行迁移后的 information_schema 提取。字段与索引以建表脚本为准；不是现有业务库的导出。

全部业务时间 DATETIME(6) 按 UTC 读写；API 使用 camelCase，SQL 使用 snake_case。BIGINT ID 经 Java Long 处理，对外序列化为字符串。生成列不可由应用写入。

## claim_contact_permissions

仅存授权开关，不复制手机号/邮箱；有效性还取决于认领和物品状态

| 字段 | MySQL 类型 | 可空 | 默认值 | 特性 | 说明 |
| --- | --- | --- | --- | --- | --- |
| claim_id | bigint | NO | &lt;NULL&gt; |  | 授权所属认领 |
| grantor_id | bigint | NO | &lt;NULL&gt; |  | 授权人；另一方从认领关系推导 |
| phone_visible | tinyint unsigned | NO | 0 |  | 自己的手机号是否授权 |
| email_visible | tinyint unsigned | NO | 0 |  | 自己的邮箱是否授权 |
| version | bigint | NO | 1 |  | 不存在时接口视作 0，首次写入为 1 |
| created_at | datetime(6) | NO | CURRENT_TIMESTAMP(6) | DEFAULT_GENERATED | UTC 首次设置时间 |
| updated_at | datetime(6) | NO | CURRENT_TIMESTAMP(6) | DEFAULT_GENERATED on update CURRENT_TIMESTAMP(6) | UTC 修改时间 |

索引：

- `idx_contact_grantor`：`grantor_id, claim_id`。
- `PRIMARY`：唯一；`claim_id, grantor_id`。

外键（复合外键按同名约束合并阅读，全部 RESTRICT）：

- `fk_contact_claim`：`claim_id` → `claims.id`。
- `fk_contact_grantor`：`grantor_id` → `users.id`。
